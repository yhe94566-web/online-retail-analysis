# online-retail-analysis
电商数据分析项目


## 项目简介
本项目基于 Kaggle 的 Online Retail II 数据集，使用 Python 完成了一次完整的电商交易数据分析。分析涵盖了数据清洗、核心指标计算、RFM 用户分层、复购率分析、首次购买到二次购买的转化漏斗构建、销售额时间趋势分析以及国家销售额排名。项目最终输出 RFM 分层结果、月度复购率、国家销售额排名等 CSV 文件，并生成可视化图表，旨在为运营提供用户价值、留存与地域增长的数据洞察。


## 数据集来源
- **名称**：Online Retail II  
- **来源**：Kaggle（https://www.kaggle.com/datasets/mashlyn/online-retail-ii-uci）  
- **描述**：该数据集包含 2009-2010 年英国一家在线零售商的交易记录，涵盖订单号、商品代码、数量、单价、客户ID、交易日期、国家等信息，原始数据约 106 万行。  
- **字段说明**：  
  - `Invoice`：发票号  
  - `StockCode`：商品代码  
  - `Description`：商品描述  
  - `Quantity`：数量  
  - `InvoiceDate`：交易日期时间  
  - `Price`：单价  
  - `Customer ID`：客户ID  
  - `Country`：国家


## 技术栈
- **Python 3**：核心编程语言  
- **pandas**：数据处理与清洗  
- **numpy**：数值计算  
- **matplotlib** & **seaborn**：数据可视化  
- **Jupyter Notebook**：交互式分析与代码呈现


- ## 分析内容与结论

### 1. 数据清洗
- 删除 `Customer ID` 为空的行（无法进行用户分析）  
- 剔除取消订单（`Invoice` 以 "C" 开头）  
- 过滤 `Quantity <= 0` 或 `Price <= 0` 的异常记录  
- 新增 `TotalAmount` 字段（`Quantity * Price`）  
- 清洗后数据量：805,549 行，唯一客户数：5,878

### 2. 整体 KPI
- **总销售额**：17,743,429.18  
- **总订单数**：36,969  
- **总客户数**：5,878  
- **客单价**：479.95  
- **人均消费**：3,018.62

### 3. RFM 用户分层
- **R（Recency）**：最近一次购买距今天数  
- **F（Frequency）**：购买次数  
- **M（Monetary）**：总消费金额  
- **分层结果**：
  - 高价值用户：9.31%（销售额贡献 22.06%）  
  - 潜力用户：8.32%（销售额贡献 6.32%）  
  - 流失用户：24.92%（销售额贡献 2.61%）  
  - 一般用户：57.45%（销售额贡献 69.01%）

### 4. 复购率分析
- **整体复购率**（购买≥2次用户占比）：**72.39%**  
- **月度复购率**：从 2010 年 1 月的 46.81% 逐步上升至 12 月的 91.11%（仅展示部分），表明用户粘性随月份提升。

### 5. 漏斗分析（首次购买 → 二次购买）
- **首次购买用户数**：5,878  
- **二次购买用户数**：4,256  
- **转化率**：72.41%  
- 说明：多数用户在首次购买后继续复购，用户留存状况良好。

### 6. 时间趋势与地域分析
- **月度销售额趋势**：整体呈上升趋势，年末（11-12 月）为销售高峰。  
- **国家销售额 Top 10**：英国、荷兰、爱尔兰、德国、法国等位列前茅，其中英国贡献了绝大部分销售额。

## 文件说明
- `online_retail_analysis.ipynb`：完整 Jupyter Notebook 代码，包含数据清洗、分析流程、可视化及结果输出。  
- `rfm_result.csv`：RFM 分层结果（包含每个用户的 R、F、M 值、评分及分层标签）。  
- `monthly_repeat_rate.csv`：月度复购率数据（月份、总购买用户数、复购用户数、复购率）。  
- `country_sales_top10.csv`：销售额 Top 10 国家列表（国家、总销售额）。  
- `monthly_sales.csv`：月度销售额数据（月份、销售额）。  
- `README.md`：项目说明文档（本文件）。
